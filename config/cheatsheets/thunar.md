  # Thunar
  | Taste          | Aktion                     |
  |----------------|----------------------------|
  | Ctrl+R / F2    | Umbenennen                 |
  | F5             | Neu laden                  |
  | Ctrl+?         | Diese Übersicht            |
  | Ctrl+L         | Pfadleiste fokussieren     |
  | Ctrl+H         | Versteckte Dateien an/aus  |

  | Ctrl+T / Ctrl+W| Tab öffnen / schließen     |
  | F3             | Split-View an/aus          |
  | Alt+↑ / Alt+←  | Übergeordneter Ordner / Zurück |
  | Ctrl+Z / Ctrl+Shift+Z | Undo / Redo         |
  | Ctrl+Shift+N   | Neuer Ordner               |

ctrl+alt+h          aus dem Ordner raus
ctrl+alt+l          in den Ordner rein / öffnen
