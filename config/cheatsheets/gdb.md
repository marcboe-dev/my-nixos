gdb <executable>    start gdb debugger

## Layout
layout next         cycle through layouts
layout src          go to src layout

## Start
run                 run application without input

## Fix broken gdb print output to the console
refresh

## Breakpoint
break+<linenumber>

## Cycle through code
next || n

## Print
print <variable-name>

## Delete Breakpoints
clear <linenumber>          delete by linenumber
delete <breakpointnuber>    delete by breakpointnumber
